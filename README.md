## Présentation

Ce portfolio met en avant mes compétences en analyse de données et en Business Intelligence :

- SQL Server et PostgreSQL ;
- Power BI et Qlik Sense ;
- Python et R ;
- Excel ;
- ETL avec SSIS ;
- statistiques, qualité des données et reporting.

Le projet principal présente la conception d'un système automatisé d'analyse des données pour **Gusunon**, réalisée dans le cadre de mon travail de fin d'études en Business Data Analysis à l'EPHEC.

## Projet principal

Le projet couvre l'ensemble d'un processus décisionnel :

1. collecte de données provenant de fichiers PDF et Excel ;
2. extraction et préparation avec Python ;
3. structuration dans SQL Server ;
4. modélisation en étoile ;
5. automatisation du chargement avec SSIS ;
6. contrôles de qualité des données ;
7. création de tableaux de bord avec Power BI.

Le jeu de données analysé comprend **30 829 lignes de transactions** couvrant la période **2021–2025**.

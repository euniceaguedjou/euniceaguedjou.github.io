# Guide simple de publication sur GitHub Pages

Ce dossier contient le portfolio prêt à être publié à l'adresse :

**https://euniceaguedjou.github.io**

## 1. Créer le dépôt

1. Connectez-vous au compte [github.com/euniceaguedjou](https://github.com/euniceaguedjou).
2. Cliquez sur le signe **+** en haut à droite, puis sur **New repository**.
3. Saisissez exactement ce nom : `euniceaguedjou.github.io`.
4. Ajoutez la description : `Portfolio professionnel de Eunice Aguedjou — Junior Data Analyst`.
5. Choisissez **Public**.
6. Ne cochez pas les options d'ajout d'un README, d'un fichier `.gitignore` ou d'une licence : ces fichiers sont déjà préparés.
7. Cliquez sur **Create repository**.

## 2. Envoyer les fichiers

1. Décompressez l'archive ZIP sur votre ordinateur. N'envoyez pas le fichier ZIP lui-même dans le dépôt.
2. Sur la page du nouveau dépôt, cliquez sur **uploading an existing file**. Si cette option n'apparaît pas, cliquez sur **Add file**, puis sur **Upload files**.
3. Glissez dans la zone d'envoi tous les éléments contenus dans le dossier décompressé :
   - `.nojekyll` ;
   - `index.html` ;
   - `styles.css` ;
   - `app.js` ;
   - `README.md` ;
   - `GUIDE_PUBLICATION_GITHUB.md` ;
   - le dossier `assets` et son contenu.
4. Dans le champ du message, écrivez : `Publication initiale du portfolio`.
5. Cliquez sur **Commit changes**.

## 3. Activer GitHub Pages

1. Dans le dépôt, cliquez sur **Settings**.
2. Dans le menu de gauche, cliquez sur **Pages**.
3. Sous **Build and deployment**, choisissez **Deploy from a branch**.
4. Dans **Branch**, sélectionnez `main` et `/(root)`.
5. Cliquez sur **Save**.
6. Patientez quelques minutes, puis ouvrez `https://euniceaguedjou.github.io`.

## 4. Mettre le portfolio à jour

### Corriger un texte

1. Ouvrez `index.html` dans le dépôt.
2. Cliquez sur l'icône en forme de crayon.
3. Modifiez seulement le texte souhaité.
4. Cliquez sur **Commit changes**.

### Remplacer le CV

1. Préparez le nouveau CV en conservant le nom `cv-eunice-aguedjou.pdf`.
2. Ouvrez le dossier `assets` dans GitHub.
3. Choisissez **Add file**, puis **Upload files**.
4. Envoyez le nouveau PDF et confirmez son remplacement.
5. Cliquez sur **Commit changes**.

### Ajouter une image de tableau de bord

1. Ouvrez le dossier `assets`.
2. Téléversez l'image avec **Add file > Upload files**.
3. Ajoutez ensuite la nouvelle image dans `index.html`, ou demandez de l'aide avant de modifier le code.

## 5. Ajouter le lien sur LinkedIn

Ajoutez `https://euniceaguedjou.github.io` dans :

- **Coordonnées > Site web > Portfolio** ;
- **Sélection > Ajouter un lien**.

Titre conseillé : **Portfolio Data Analyst — Eunice Aguedjou**.
